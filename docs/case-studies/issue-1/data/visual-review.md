# Visual review of the game concepts

Review date: 2026-10-15. Open the
[visual catalog](../../../master-plan/concepts/README.md) for the full artwork.

## Method and limits

All four views of every game listed below were inspected in temporary review
sheets, with one row per game and one column per direction. This overview review
checks whether the interaction is recognizable, the compositions differ and the
art can support a prototype-selection discussion. Review sheets are not delivered
as concept art and do not count toward the four independently generated images.

Pair Friends and Blossom Swap gameplay, Research Backpack materials and Circular
Factory expanded play were also inspected at full native resolution as proposed
pull-request previews.
Automated checks separately verify coverage, file signatures, native dimensions,
hashes, exact prompts, thumbnails and navigation links.

These observations do not validate puzzle solvability, correct equations,
scientific diagrams, language instruction, safe real-world procedures or
educational efficacy. Generated labels and suggested moves need authored data
and subject review before implementation. Character continuity and accessibility
also need review in a playable prototype.

## Collection observations

BC-01–BC-16: all four views inspected in temporary review sheets. Original compositions and mechanics are recognizable; settings, perspectives and materials vary. Card/board numbers and rule-valid states are concept proposals requiring implementation review, as documented on each page.

BC-17–BC-18: all four views reviewed; card interactions and cooperative objectives remain distinct. All 72 board/card images have been inspected.

BD-01–BD-07: all four views reviewed. Coloring, symmetry, clothing design, origami, programming, map-making and marble-run interactions are distinct and recognizable. The concept boards need rule validation before implementation.

BD-08–BD-14: all four views reviewed. Flipbook frames, level editing, accessible building, voxel greenhouse, room planning, backpack packing and pottery show their intended interactions with distinct compositions. All 56 Build and Create images inspected.

ML-01–ML-04: all four views inspected. Arithmetic gates, number-line stepping stones, multiplication arrays and sequence trains are recognizable. Number placement in alternate views requires authored, validated production boards; these remain concept proposals.

ML-05–ML-12: all four views inspected. Sudoku-style grids, treasure clues, fractions, balance, sum grids, recursion, binary beads and attribute patterns are recognizable and visually distinct. Illustrated clues and equations are not validated level data.

ML-13–ML-20: all four views reviewed. Deduction tables, probability wheels, compass construction, graph routes, proof tiles, bridge networks, inequalities and expression tiles match their intended visual mechanics. Exact proofs, arithmetic and rule-valid grids require domain review and authored data before prototyping. All 80 Math and Logic images inspected.

MR-01–MR-10: all four views inspected. Sequence pads, drums, keyboard lanes, rhythm tracks, note matching, composition grids, conducting, pitch tracing, dance dialogue and rhythm platforms are visually recognizable. Notation and interaction timing need implementation validation. All 40 Music and Rhythm images inspected.

NC-01–NC-17: all four views inspected across five review sheets. Hygiene, weather clothing, recycling, bird observation, ocean cleanup, pollination, animal care, rest, plants, cooking, rotation, migration, aquariums, forest planning, cleaning, terrariums and magnet cleanup are recognizable. Scientific relationships, local recycling rules and care advice need expert validation before implementation. All 68 Nature and Care images inspected. The Research Backpack details preview was additionally inspected at full native resolution.
