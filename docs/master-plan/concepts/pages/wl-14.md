# Prime Sprites

WL-14 · [Words and languages](../wl.md) · Cx 3 · W3 · Original catalog

**The idea:** Connect subject, verb and object cards into a visible sentence path.

| Decision             | Proposal                                                                                                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Familiar mechanic    | Sentence building                                                                                                                                                                           |
| Learning objective   | Grammar, word order across languages                                                                                                                                                        |
| First prototype      | One authored challenge built around the interaction above, with a clear goal, immediate feedback, restart and unlimited retries.                                                            |
| Technology           | React shell + PixiJS; use the shared simulation adapter only where motion or agent behavior requires it. Start with one bounded scene and measured frame time.                              |
| Scope boundary       | One bounded scenario and one core system; defer a full campaign, network play and production-scale content.                                                                                 |
| Reuse                | Shared input, saves, accessibility, seeded state and the words and languages collection shell.                                                                                              |
| Prototype acceptance | A player can identify the next action from the screen, complete one challenge, explain the practiced idea and restart without help. Check touch and keyboard play at narrow and wide sizes. |
| Main uncertainty     | Test whether the lesson follows from play and whether the first interaction is understandable without reading.                                                                              |

## Estimated plan

**First playable version:** 24 scenes where voiced subject, verb and object cards are linked into a sentence path that the sprites then act out, in two languages with different word order. Tenses and more languages are deferred.

| Measure              | Estimate                                                                               |
| -------------------- | -------------------------------------------------------------------------------------- |
| Youngest age         | 5+                                                                                     |
| Toddler learnability | 2 of 5 — Needs simple rules, turns, a sequence or remembering several steps; ages 4-6. |
| Code                 | 1600 LOC, 13.3 days                                                                    |
| Assets               | 186 hours, 31 days                                                                     |
| Effort               | 44.3 days, risk 2 of 5                                                                 |
| Start score          | 88.6 (rank 208 of 300; lower is better)                                                |

**Algorithms:** `drag-drop-snap` (Drag and snap, 150 LOC) · `word-list` (Word lists and validation, 150 LOC) · `graph-network` (Node-link graph, 300 LOC) · `tween-cause-effect` (Cause-and-effect animation, 100 LOC)

**Assets:** 30 sprites, 12 animations, 4 backgrounds, 5 UI screens, 14 sound effects, 2 music tracks, 80 voice lines, 24 authored levels, 120 content items

How the numbers are computed: [development plan](../../development-plan.md#how-the-scores-work).

## Design checks before prototyping

- Learning target: **Grammar, word order across languages**. Ask a domain reviewer to validate factual content in the mechanic.
- Keep goals cooperative or self-directed, using resources and needs. Avoid purchasable power. No pressure timers in the accessible mode.
- Use original layouts and character designs; the [legal checklist](../../legal.md) applies even when a mechanic is familiar.
- Choose the minimum [fidelity level](../../simulation-engine.md#determinism-and-fidelity-levels) the lesson needs; concept art does not establish scientific accuracy.
- Review silhouettes, text alternatives, reduced motion and non-color cues against the [adorability gate](../../lore/adorability-gate.md).
